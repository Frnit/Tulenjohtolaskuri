# P2.5 browser adapters

Change identifier: `CHG-P2-5-BROWSER-ADAPTERS-001`.

## Accepted behavior

- Camera, geolocation and orientation browser APIs are owned by dedicated
  adapters. Page scripts consume their common state and do not retain browser
  resource handles.
- Each adapter reports availability, permission, lifecycle status, latest value,
  observation time, structured error and manual fallback.
- Camera tracks, geolocation watches and orientation listeners are released by
  `stop()`, `dispose()` and `pagehide`.
- Freezing an AR image pauses presentation without releasing the camera. Leaving
  the page releases the camera stream.
- Missing APIs and denied permissions affect only the sensor feature. Main-page
  manual inputs and the rest of the AR interface continue to work.
- Browser error details and sensor values are not written into notices or logs.

## Startup decision

P2.5 preserves the existing automatic AR startup for camera and geolocation.
Orientation starts automatically only where no explicit permission gesture is
required. On platforms requiring that gesture, the AR page shows a sensor button
and requests permission only after the user presses it. This keeps the current
workflow while preventing an automatic permission-request loop.
