# P2.2 startup repair

Change: `CHG-P2-2-STARTUP-001`.

## Scope

The main-page startup handler called the nonexistent `updateSel()` function even
though the profile selector implementation is named `uSel()`. The resulting
`ReferenceError` stopped profile population and prevented the existing AR handoff
from being consumed.

The repair changes only that call site. It does not refactor startup, persistence,
rendering, service-worker behavior, or domain calculations.

## Acceptance evidence

- `ACC-START-001` verifies target initialization, saved-profile population and a
  startup free of page errors.
- `ACC-HANDOFF-001` verifies that an incoming AR distance is loaded, removed from
  LocalStorage, routed to the size workflow, and not consumed again after reload.

The former `DEF-START-001` reproducer and the affected baseline characterization
tests were retired. The audited failure remains documented in traceability and Git
history.
