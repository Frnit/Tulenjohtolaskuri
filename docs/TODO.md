# Tuoteominaisuuksien tehtävälista

- [ ] `REQ-POSITION-INPUT-001` — Oman sijainnin pitää voida ilmoittaa WGS84-muodon lisäksi vähintään MGRS-muodossa. Toteutuksessa säilytetään WGS84-vaihtoehto ja määritellään syötteen validointi sekä muunnoksen hyväksymistestit ennen käyttöönottoa.
- [ ] `REQ-EXAMPLE-SIZE-LABELS-001` — Esimerkkimallien kokotiedot pitää esittää yksiselitteisesti. Jokaisesta arvosta tulee käydä ilmi mitattava ulottuvuus, yksikkö ja se, missä työnkulussa arvoa käytetään.
