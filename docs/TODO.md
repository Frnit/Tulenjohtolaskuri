# Tuoteominaisuuksien tehtävälista

- [x] `REQ-POSITION-INPUT-001` — Oman sijainnin voi ilmoittaa WGS84- tai MGRS-muodossa. MGRS-syöte validoidaan paikallisesti, muunnetaan ruudun keskipisteeksi WGS84-koordinaateiksi ja varmennetaan tunnetuilla MGRS/UTM-vektoreilla sekä selaimen hyväksymistesteillä.
- [x] `REQ-AR-TARGET-ORIENTATION-001` — AR-tilan ristikytkimellä voi kiertää mittauskehystä sekä säätää korkokulmaa. Suunta-anturin korkokulma toimii lähtöarvona, manuaalinen säätö korjauksena ja korkokulma siirtyy etäisyystuloksen mukana pääsivulle.
- [ ] **LOW** `REQ-AR-PERSPECTIVE-CORRECTION-001` — Suunnittele kuvatunnistuksen yhteyteen perspektiivin ja lyhentymän korjaus. Tunnistetun kohteen asennon pitää ohjata mitattavan ulottuvuuden kuvallista korjausta, ja manuaalinen hienosäätö säilytetään.
- [x] `REQ-EXAMPLE-SIZE-LABELS-001` — Esimerkkimallien kokotiedot esitetään yksiselitteisesti. Jokaisesta arvosta käy ilmi mitattava ulottuvuus, yksikkö ja se, missä työnkulussa arvoa käytetään.
