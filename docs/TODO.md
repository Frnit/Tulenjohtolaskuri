# Tuoteominaisuuksien tehtävälista

- [ ] `REQ-POSITION-INPUT-001` — Oman sijainnin pitää voida ilmoittaa WGS84-muodon lisäksi vähintään MGRS-muodossa. Toteutuksessa säilytetään WGS84-vaihtoehto ja määritellään syötteen validointi sekä muunnoksen hyväksymistestit ennen käyttöönottoa.
- [ ] **LOW** `REQ-AR-TARGET-ORIENTATION-001` — AR-tilaan tarvitaan manuaalinen säätö, jolla käyttäjä voi kiertää mittauskehystä vastaamaan katsottavan kohteen todellista asentoa. Kun kuvatunnistus on käytössä, sovellus asettaa kiertokulman automaattisesti; manuaalinen hienosäätö säilytetään korjausmahdollisuutena.
- [x] `REQ-EXAMPLE-SIZE-LABELS-001` — Esimerkkimallien kokotiedot esitetään yksiselitteisesti. Jokaisesta arvosta käy ilmi mitattava ulottuvuus, yksikkö ja se, missä työnkulussa arvoa käytetään.
